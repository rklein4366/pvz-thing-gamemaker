Layout changes in this build
----------------------------
- PC board offset: 220px; PC scene height offset: 0px; street pan: 380px.
- The PC board uses native lawn artwork at (-220 - camera_x, 0) with no extra Xbox/QEWide bush overlays.
- Lawn mowers begin at the PC source position x=-160 and correct row y positions.
- Chooser silhouettes are drawn for exactly 5 rows (40 positions), with six bank slots under selected packets.
- Seed cost text uses Pico129; chooser heading uses the gold DwarvenTodcraft18Yellow atlas; tooltip text uses BrianneTod12.
- The sun bank uses ContinuumBold14 when the GIF atlas above is installed; while it is absent, the renderer falls back to an included PvZ bitmap font instead of GameMaker's default font.

Verification caveat
-------------------
Source files passed static delimiter checks and the project archive integrity check. GameMaker itself was not available here,
so run the project in GameMaker to verify the visuals / interactions in-game.
